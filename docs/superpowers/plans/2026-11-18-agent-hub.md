# Agent Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private, live claude.ai Artifact page where Anay sees and manages all his Claude agents (sessions + scheduled tasks) from his phone.

**Architecture:** Pure logic (status mapping, board derivation, formatting, prompt building) lives in `agent-hub/src/logic.js`, tested with `node --test`. UI and capability calls live in `agent-hub/src/app.js`. A tiny build script inlines both into `agent-hub/src/page.html` and writes `agent-hub/dist/agent-hub.html`, the single file published with the Artifact tool, declaring the `mcp` (Claude Code Remote connector) and `sample` capabilities.

**Tech Stack:** Vanilla HTML/CSS/JS (no framework, no CDN libraries), Node 18+ built-in test runner, claude.ai Artifact runtime contract 0.2.96 (`claude.use("mcp")`, `claude.use("sample")`).

**Spec:** `docs/superpowers/specs/2026-11-17-agent-hub-design.md`

## Global Constraints

- Connector display name: `Claude Code Remote`. Manifest tools exactly: `list_sessions`, `get_session`, `list_events`, `list_triggers`, `send_message`, `interrupt_session`, `archive_session`, `fire_trigger`, `update_trigger`.
- Capabilities on publish: `{mcp: {servers: [{server: "Claude Code Remote", tools: [...above]}]}, sample: {}}`.
- Gate every feature on `listTools("Claude Code Remote")`; unlisted tool or `blocked_by_policy` → feature shown as unavailable, never called.
- Errors: branch on `code`; retry only `retryable` reads, once; never auto-retry writes; authorization denials (`needs_reauth`, `server_not_connected`, `blocked_by_policy`, `approval_required`, `not_in_manifest`) hide that section's data.
- Reads via `watchTool`: sessions `refetchInterval: 30000`, triggers `60000`, open detail `30000`. Actions via `callTool`, then `mcp.invalidate("Claude Code Remote")`.
- All agent-written text (titles, summaries, transcripts) goes into the DOM via `textContent` only. No `innerHTML` with data anywhere.
- No `alert/confirm/prompt`. Interrupt, archive, and pause/resume use an inline Confirm/Cancel row.
- Artifact page contract: own `<title>Agent Hub</title>`, `<meta name="claude:viewport-fit-sides" content="cover">`, theme tokens on `:root` + both dark blocks, `body` background from a token, side gutter `max(16px, env(safe-area-inset-left/right, 0px))`, no horizontal scroll at 400px, sticky header `top: env(safe-area-inset-top, 0px)` with `body::before` band.
- Fonts: Google Fonts only, with fallback stacks.
- Session links: `https://claude.ai/code/<session_id>`.
- Times shown in the viewer's local time zone.

## Review Focus

1. **Zero sessions / zero triggers** → each section shows a designed empty state, never a blank box. (Task 2, Task 5)
2. **Sessions missing optional fields** (no `post_turn_summary`, no `unread`, no `environment_kind`, unknown `status_bucket`) → card renders with fallbacks ("No summary yet", status "Unknown" grouped with Done). (Task 1, Task 2)
3. **Hostile text in titles/summaries** (`<img src=x onerror=…>`) → shown literally. (Task 6 test via build check: `grep -c innerHTML` limited to static templates)
4. **More than 50 sessions** (`has_more: true`) → board shows a "Showing your 50 most recent agents" note, no crash, no silent truncation. (Task 2)
5. **Unparseable or exotic cron** (`CRON_TZ=… 37 8 * * 1-5`, `*/15 * * * *`) → humanized when recognized, else raw expression shown. (Task 3)

### Task 2: Board derivation

**Files:** Modify `agent-hub/src/logic.js`, `agent-hub/test/logic.test.mjs`

**Interfaces:**
- Consumes: `statusOf`.
- Produces: `deriveBoard(sessions: Session[], {showArchived=false, hasMore=false}) -> {needsYou: Card[], working: Card[], done: Card[], archived: Card[], counts: {failed, blocked, review, working, done, unread}, truncated: boolean, empty: boolean}` where `Card = {id, title, status, summary, needsAction, updatedAt, where: 'Mac'|'Cloud'|'', unread: boolean, url, helpers: Card[]}`.
  - `needsYou`: urgent statuses, sorted by `rank` then `updatedAt` desc.

  - `title` fallback `"Untitled agent"`; `summary` fallback `"No summary yet"`; `where`: `bridge`→`Mac`, `anthropic_cloud`→`Cloud`, else `''`.
  - `truncated = hasMore`; `empty` when no non-archived cards.

### Task 3: Triggers, transcript turns, standup prompt, error views

**Files:** Modify `agent-hub/src/logic.js`, `agent-hub/test/logic.test.mjs`

**Interfaces:**
- Produces:
  - `humanizeCron(expr: string) -> string`: handles `m h * * *` → `"Daily at HH:MM UTC"`, `m h * * 1-5` → `"Weekdays at HH:MM UTC"`, `0 * * * *` → `"Hourly"`, `CRON_TZ=Zone m h * * *` → `"Daily at HH:MM (Zone)"`; anything else returns `expr` unchanged. The page converts UTC times to local separately; this function only labels.
  - `triggerCard(t, nowMs) -> {id, name, schedule, enabled, nextRun: string, last: {label: 'Succeeded'|'Failed'|'Running'|'Never run', ok: boolean|null, when: string, sessionUrl: string|null}}`. `last_run.status` `ROUTINE_RUN_STATUS_SUCCEEDED`→Succeeded/ok true, `..._FAILED`→Failed/false, other present→Running/null, absent→Never run/null. `sessionUrl` from `last_run.session_id`.
  - `extractTurns(events: Event[]) -> Turn[]` where `Turn = {role: 'you'|'agent'|'end', text, at}`: from `user` events (text blocks joined; skip events whose text is empty or only tool results), `assistant` events (text blocks only), `result` events → `{role:'end', text: is_error ? 'Turn ended with an error' : 'Turn finished'}`. Keep chronological order. Text truncated to 600 chars with `…`. Accepts both `ev.user.message.content` and `ev.user.content` shapes, and string content; builder confirms against one real read.
  - `standupMessages(board, nowMs) -> string`: a single prompt string containing instructions ("Write 4–8 plain-language bullets. Start with what needs Anay. Then who finished what today, then who is still working. No headings, no preamble.") followed by one line per card: `- [status label] title — summary (updated relativeTime)`. Only cards updated in the last 24h plus all `needsYou`.
  - `errorView(code: string, server='Claude Code Remote') -> {kind: 'hide'|'retry'|'info', text}`: `needs_reauth` → hide, "Reconnect Claude Code Remote in claude.ai Settings → Connectors."; `server_not_connected`/`selection_required` → hide, "Add or choose the Claude Code Remote connector in claude.ai Settings → Connectors."; `blocked_by_policy` → hide, "Your organization doesn't allow this."; `approval_required`/`not_in_manifest`/`consent_required` → hide, "Allow Claude Code Remote for this page to see your agents."; `server_unavailable`/`rate_limited` → retry, "Couldn't reach your agents. Retrying…"; `not_granted`/`capability_disabled`/`capability_removed` → hide, "Live agent data isn't available in this view. Open the page in claude.ai."; default → info, "Something went wrong loading this section."

### Task 5: Live data, board, and crew rendering

**Files:** Modify `agent-hub/src/app.js`

**Interfaces:**
- Consumes: `deriveBoard`, `statusOf`, `relativeTime`, `triggerCard`, `humanizeCron`, `errorView`, `unwrap`.
- Produces in `app.js`: `state = {mcp, tools: Set<string>, sessions, triggers, showArchived, filter}`; `has(tool) -> boolean`; `renderBoard()`, `renderCrew()`, `openSheet(id)` (Task 6 fills it).
- Behaviour:
  - Boot: `mcp = await claude.use("mcp")`; null → `#notice` from `errorView('not_granted')`. Else `listTools("Claude Code Remote")` → `tools`; missing server → `errorView('server_not_connected')`.
  - `watchTool(..., 'list_sessions', {mine:true, limit:50}, handler, {refetchInterval:30000})`; `list_triggers` `{limit:50}` at 60000. Handler: data → store, re-render, set `#updated` from `result.cache?.storedAt ?? Date.now()`; error → `errorView`; `hide` clears that section; `retry`/`info` keeps last data and shows a small inline note. If both sections hold the same hide-code, show one `#notice` instead.
  - `#refresh` → `mcp.invalidate("Claude Code Remote")`.
  - Cards: title, status pill, `where` tag, summary, relative time, unread dot, "+N helper agents", "Open session ↗" link. Needs-you items get the severity stripe. Summary chips filter the board (tap again to clear). "Show archived" toggle. `truncated` → note under board.
  - Crew rows: name, schedule (humanized; UTC times converted to local in display when the label ends in `UTC`), next run local time, last result + link, enabled/paused pill.
  - The relative-time labels re-render every 30s from a timer (no network).

### Task 6: Agent detail sheet and manager actions

**Files:** Modify `agent-hub/src/app.js`, `agent-hub/src/page.html` (sheet styles if needed)

**Interfaces:**
- Consumes: `extractTurns`, `errorView`, `has`.
- Produces: `openSheet(id)`, `closeSheet()`, `confirmRow(button, label, run: () => Promise)`, `runAction(tool, input, okText)`.
- Behaviour:
  - Sheet shows title, status, where, created/updated, `needs_action` if present, helper list, last ~10 turns (watch `list_events {session_id, kinds:['user','assistant','result'], limit:100}` at 30000; if fewer than 10 turns and `has_more`, page back with `before_id: first_id` up to 3 pages total via `callTool`).
  - Actions (each rendered only if `has(tool)`): message composer (`send_message {session_id, message}`; Send disabled when empty; note "Arrives as a message from another Claude session."), Stop (`interrupt_session`, shown only when status is `working`), Archive (`archive_session`, hidden when archived). Stop/Archive use `confirmRow`.
  - Crew row actions: Run now (`fire_trigger {trigger_id}`), Pause/Resume (`update_trigger {trigger_id, enabled}`, via `confirmRow`).
  - `runAction`: disables the button, `callTool`, on success shows `okText` inline ("Sent", "Stopped", "Archived", "Started", "Paused", "Resumed") then `invalidate`; on failure shows `errorView(code).text` inline (or the tool's message for `tool_error`); never retries. On `server_unavailable`/`upstream_error` text says "It may or may not have gone through. Check again before retrying."
  - Sheet closes on Escape, backdrop tap, and a Close button; focus returns to the card.
